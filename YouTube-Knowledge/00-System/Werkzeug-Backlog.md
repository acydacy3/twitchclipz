# Werkzeug-Backlog — kostenlos / GitHub (nach ROI fürs 10-Mio-Ziel)

1. **Manim** (pip, gratis) — Erklär-Animation: Querschnitte, Karten, Zeitleisten, Mechanik (Dahlbuschbombe, Höhlengeometrie). Größter Hebel für „weg von Standbild+VO". → [[Experiment-Cheap-Animation-Querschnitt]], [[Ziel-YPP-Monetarisierung]]
