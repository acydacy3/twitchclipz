# Schnitt-Protokoll — vor JEDEM Video-/Short-Schnitt

Verbindliche Reihenfolge (Nutzer-Regel, 19.08.). Zweck: an alle Audit-/Analyse-
Erkenntnisse erinnern, kostenlos aktuell halten, keine Limits/Credits verschwenden.

0. **Wissen laden (gratis):** CLAUDE.md ist geladen; Längen-/Hook-/Titel-/Caption-Learnings direkt nutzen. Nur bei **echter** Unsicherheit **ein** kostenloser Check über YouTube Data-/Analytics-API. **vidIQ nur auf Anfrage** (WASTE meiden, nicht Qualität — [[Guardrails]] #8, Ressourcen-Prinzip).
1. **Erinnern, was gewinnt:** Hook entscheidet, nicht Sekundenzahl. Bester Short: „33 Mann fahren ein. 700 Meter tief." (26 s → 1.286). Zone 19–39 s, tote Sekunden killen. Retention < 60 % = Anfang trägt nicht. YouTube-Länge NICHT nach TikTok. → [[Learning-Retention-und-Laenge]]
2. **Erste 3 Sekunden:** Kalt-Einstieg, keine Titelansage. Einstellung 1 = Detail, ~2–3 s; erster harter Schnitt ≤ Sek 3. **Untertitel = Stimme.** Hook-Banner optional abweichend (Test). → [[Learning-Hooks]], [[Learning-Captions]]
3. **Titel:** EIN starkes Keyword, Aussage bis Zeichen 35. Keine Teilnummer/Emoji im Titel. → [[Learning-Titel]]
4. **Virale Schnitt-Technik:** Pattern-Interrupt; alle Grenzen auf Sprechpausen ≥ 0,42 s; Tonart je Short wechseln; „TEIL X"-Leiste; erster Frame = stärkstes Bild; Mehrfach-Ausschnitt (ein Bild → 3–5 Einstellungen). → [[Learning-Storytelling-Shorts]], [[Learning-Editing-Video]]
5. **Captions (ASS-Karaoke):** 104 bei 1080, aktives Wort gold 118 %, Umbruch nach Breite (~15 Z, Ziel 85–90 %), Endzeiten auf nächster-Start−0,02 s, 21 Z/s, 45 Z/Zeile, PlayResX/Y gesetzt, .srt separat hoch. → [[Learning-Captions]]
6. **Nach dem Schnitt:** jede neue Erkenntnis (Länge/Hook/Caption) SOFORT ins Vault → [[Memory-Workflow]]. Die nächste Session baut darauf auf.
