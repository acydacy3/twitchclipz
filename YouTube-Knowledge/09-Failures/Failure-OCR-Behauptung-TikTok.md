# Failure: „TikTok liest eingebrannten Text per OCR und indexiert ihn"

- **Behauptung:** In einer Session als Fakt behauptet — auch dem Nutzer gegenüber.
- **Prüfung:** **Keine Primärquelle.** TikToks einziges offizielles Dokument zum Empfehlungssystem (18.06.2020) nennt nur Bildunterschriften, Sounds, Hashtags. Praktisch alle Ratgeber behaupten OCR trotzdem.
- **Warum das ein Fehler war:** eine plausible Vermutung wurde als Learning ausgegeben → verletzt [[Knowledge-Architecture]] §6 (keine Halluzinationen).
- **Was trotzdem gilt:** Die abgeleitete Taktik gilt beidseitig — die **Caption liefert, was im Voiceover fehlt** (Genre, Ort, Jahr). Wird Text gelesen: nicht doppeln. Wird er nicht gelesen: einziger Textkanal.
- **Do not repeat unless:** TikTok bestätigt OCR offiziell **oder** ein sauberer Test zeigt Indexierung von reinem Bildtext.
